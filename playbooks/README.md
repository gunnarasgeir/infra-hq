# Playbooks

Step-by-step guides for jobs users often ask for. They are provider-neutral: combine them with the recipes in `services/` for the actual commands.

| Playbook | When the user says something like |
|---|---|
| [`move-hosting.md`](move-hosting.md) | "Move my site from X to Y" |
| [`dns-cleanup.md`](dns-cleanup.md) | "Clean up old DNS records", "what is all this in my DNS?" |
| [`backup-audit.md`](backup-audit.md) | "Is everything backed up?", "could I recover if X died?" |

When you finish a job that is likely to come up again and has no playbook, write one.
